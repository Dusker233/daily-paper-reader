## 1. 问题与背景
软件漏洞依然是现代数字基础设施面临的重大威胁。尽管静态应用安全测试（SAST）工具被广泛应用，但其高假阳性率依然是一个严重问题，导致开发者忽视安全警告，未能有效修复漏洞。TitanCA 项目通过多种大语言模型（LLM）驱动的智能体协作，提出了一种新的漏洞发现方法。

## 2. 核心思路 / 方法
TitanCA 构建了一个四模块的管道，包括匹配、筛选、检查和适应，通过多个 LLM 智能体的协作，逐步提高漏洞检测的精度。与传统方法不同，TitanCA 通过模型间的配合而非单一模型的扩展，优先提高精度并减少假阳性。同时，该系统能够根据具体组织的需求进行领域适配，从而弥补了通用模型的不足。

## 3. 结果与结论
TitanCA 已分析了超过 127,000 个 GitHub 仓库，发现了 203 个零日漏洞，并发布了 118 个 CVE。实验表明，通过多智能体的协作，TitanCA 的漏洞发现能力远超传统的 SAST 工具，并且能够持续提升精度。

## 4. 局限与适用边界
TitanCA 目前只针对功能层面的漏洞检测，尚未扩展到更广泛的安全推理能力。此外，系统的表现依赖于目标环境的代码库和编程实践，因此在不同环境中的适用性仍需进一步验证。

## Abstract
Software vulnerabilities remain one of the most persistent threats to modern digital infrastructure. While static application security testing (SAST) tools have long served as the first line of defense, they suffer from high false-positive rates. This article presents TitanCA, a collaborative project between Singapore Management University and GovTech Singapore that orchestrates multiple large language model (LLM)-powered agents into a unified vulnerability discovery pipeline. Applied in open-source software, TitanCA has discovered 203 confirmed zero-day vulnerabilities and yielded 118 CVEs. We describe the four-module architecture, i.e., matching, filtering, inspection, and adaptation, and share key lessons from building and deploying an LLM-based vulnerability discovery solution in practice.

## 4. 方法详解
**管线概览**：四模块分层处理，每层输出逐步精炼（Figure 1）。

### Module 1: Matcher (VulCoCo)
- 功能：漏洞克隆检测，匹配已知漏洞函数（NVD、TitanVul 数据集）  
- 方法：向量相似度 + LLM 语义验证  
- 特性：高召回，若匹配成功直接标记，不进入后续模块

### Module 2: Filter (R2Vul)
- 功能：筛选 Matcher 未识别但可能存在的新漏洞  
- 方法：结构化推理蒸馏 + 强化学习 (RLAIF)  
- 输出：置信度分数 $\text{confidence} = \sigma(\text{log-odds})$  
- 效果：误报率从 28% 降到 20%，召回 >77%（Section 4）

### Module 3: Inspector (VulTrial)
- 功能：多智能体对抗性审查（模拟法庭）  
- 角色：Security Researcher, Code Author, Moderator, Review Board  
- 作用：降低单模型偏见，发现微妙漏洞

### Module 4: Adapter (PairVul)
- 功能：领域特定适配  
- 方法：分析部署期误报 → LLM 重新标注 → 微调模型  
- 作用：提升特定组织环境下的检测精度

**数据基础**：
- CleanVul：清理训练标签噪声  
- TitanVul / BenchVul：覆盖 MITRE Top-25 CWE，验证泛化能力  
- 规模：342,000 样本、500 TB 工程基础设施
