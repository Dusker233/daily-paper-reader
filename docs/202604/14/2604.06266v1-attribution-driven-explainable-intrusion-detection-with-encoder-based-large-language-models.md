## 摘要
软件定义网络（SDN）提高了网络灵活性，但也增加了对可靠且可解释的入侵检测的需求。由于大型语言模型（LLM）具有强大的表示学习能力，近年来它们在网络安全任务中得到了探索；然而，它们缺乏透明性，限制了它们在安全关键环境中的实际应用。因此，理解LLM是如何做出决策的至关重要。本文提出了一种基于归因分析的方法，利用流量级特征对编码器驱动的LLM进行网络入侵检测。归因分析表明，模型决策受到有意义的流量行为模式的驱动，从而提高了基于变换器的SDN入侵检测的透明度和信任度。这些模式与已建立的入侵检测原理一致，表明LLM通过流量动态学习攻击行为。本研究展示了归因方法在验证和建立基于LLM的安全分析信任中的价值。

## Abstract
Software-Defined Networking (SDN) improves network flexibility but also increases the need for reliable and interpretable intrusion detection. Large Language Models (LLMs) have recently been explored for cybersecurity tasks due to their strong representation learning capabilities; however, their lack of transparency limits their practical adoption in security-critical environments. Understanding how LLMs make decisions is therefore essential. This paper presents an attribution-driven analysis of encoder-based LLMs for network intrusion detection using flow-level traffic features. Attribution analysis demonstrates that model decisions are driven by meaningful traffic behavior patterns, improving transparency and trust in transformer-based SDN intrusion detection. These patterns align with established intrusion detection principles, indicating that LLMs learn attack behavior from traffic dynamics. This work demonstrates the value of attribution methods for validating and trusting LLM-based security analysis.

## 1. 核心问题与整体含义
- **研究动机**  
  软件定义网络（SDN）通过集中控制和灵活流量管理提升了网络性能，但同时引入了复杂的安全挑战，尤其是在实时监控大量流量时。传统入侵检测系统（IDS）依赖人工特征工程，虽然有效，但缺乏可解释性。
- **背景与意义**  
  大型语言模型（LLM）具备强大的表示学习能力，已被用于网络安全任务。然而，大多数研究将其视为黑箱分类器，缺乏透明度。安全关键场景中，理解模型为什么判断流量为恶意是至关重要的。因此，本文关注**可解释性和可信度**，而非单纯追求检测精度。

## 2. 方法论
- **核心思想**  
  结合编码器型LLM（RoBERTa、DeBERTa）和归因分析（Integrated Gradients, IG）对流量级特征进行入侵检测，提供可解释、可信的模型决策。
- **数据表示**  
  - 将每个流（flow-level）特征向量 $x = (x_1, x_2, ..., x_d)$ 转换为有序文本描述：
    ```
    s(x) = "Feature1 is x1. Feature2 is x2. ... Feature d is xd."
    ```
  - 保证特征顺序一致，实现输入 token 与原始特征的一一映射，便于可解释性分析。
- **模型架构**  
  - 单头分类器，将编码器输出接到分类层，实现三类粗粒度检测：Benign / DDoS / Web Attack（Web Attack 合并了 Brute Force、XSS、SQL Injection）。
  - RoBERTa：12 层编码器，标准 Transformer，强调高对比特征。
  - DeBERTa：增强 Transformer，区分内容与位置注意力，更好表示时间和行为特征。
- **归因方法**  
  - Integrated Gradients（IG）计算每个输入特征对预测的贡献：
    $$
    IG_i(x) = (x_i - x'_i) \int_{0}^{1} \frac{\partial F(x' + \alpha(x-x'))}{\partial x_i} d\alpha
    $$
  - 输出 token-level 归因分数，并映射回原始特征，揭示模型决策依据。

## 6. 主要结论与发现
- 两种编码器型 LLM 在整体检测上表现均非常优秀（尤其是 Benign / DDoS）。
- DeBERTa 对少数类 Web Attack 检测更稳健（F1 0.9717 > RoBERTa 0.9130），归因显示其利用分布式、行为中心的特征。
- RoBERTa 更依赖单一高对比特征（如 Destination Port、Flow IAT extremes）。
- IG 归因显示，模型决策与已知入侵检测原理高度一致：
  - Benign：弱或分散特征
  - DDoS：强度和重复性行为
  - Web Attack：时间模式和流量动态

## 7. 优点

- 综合使用 RoBERTa 与 DeBERTa，比对架构差异对决策与归因的影响。
- IG 归因提供明确决策依据，增强了模型在 SDN 中的可信度。
- 实验设计公平，采用去重、类别加权和宏 F1 指标评估少数类性能。
