## 摘要
软件定义网络（SDN）提高了网络灵活性，但也增加了对可靠和可解释的入侵检测的需求。近年来，由于大型语言模型（LLM）强大的表示学习能力，它们被探索应用于网络安全任务；然而，由于缺乏透明性，限制了它们在安全关键环境中的实际应用。因此，理解LLM如何做出决策至关重要。本文提出了一种基于归因的分析方法，用于使用流级流量特征进行网络入侵检测的编码器驱动LLM。归因分析表明，模型的决策是由有意义的流量行为模式驱动的，从而提高了基于变换器的SDN入侵检测的透明性和信任度。这些模式与已建立的入侵检测原则一致，表明LLM从流量动态中学习攻击行为。本研究展示了归因方法在验证和信任基于LLM的安全分析中的价值。

## Abstract
Software-Defined Networking (SDN) improves network flexibility but also increases the need for reliable and interpretable intrusion detection. Large Language Models (LLMs) have recently been explored for cybersecurity tasks due to their strong representation learning capabilities; however, their lack of transparency limits their practical adoption in security-critical environments. Understanding how LLMs make decisions is therefore essential. This paper presents an attribution-driven analysis of encoder-based LLMs for network intrusion detection using flow-level traffic features. Attribution analysis demonstrates that model decisions are driven by meaningful traffic behavior patterns, improving transparency and trust in transformer-based SDN intrusion detection. These patterns align with established intrusion detection principles, indicating that LLMs learn attack behavior from traffic dynamics. This work demonstrates the value of attribution methods for validating and trusting LLM-based security analysis.

- **问题核心**：大型语言模型（LLM）在表示学习能力上具有优势，但在网络安全场景中多被视为“黑箱”，缺乏透明性。本文关注如何提升基于编码器的LLM在SDN入侵检测中的可解释性，使其决策能够被理解和验证。
- **整体意义**：研究通过归因分析揭示LLM决策机制，确保模型依赖真实的流量行为特征，而非数据集偏差或“捷径”，为SDN环境中的可信入侵检测提供方法论基础。

## 2. 方法论
- **核心思想**：
  - 将流级网络特征序列化为文本形式，使编码器型LLM能够直接处理结构化流量数据。
  - 采用归因分析（Integrated Gradients, IG）量化每个特征对模型输出的贡献，从而解释模型决策。
- **关键技术细节**：
  - **数据表示**：每条流量特征向量 $x = (x_1, x_2, ..., x_d)$ 被转化为文本序列：
    ```
    s(x) = "Feature1 is x1. Feature2 is x2. ... Featured is xd."
    ```
    保证了特征顺序一致性，并可直接映射回原始数值特征。
  - **模型架构**：
    - 使用两种编码器型LLM：RoBERTa（标准Transformer编码器）与DeBERTa（改进的注意力机制，内容与位置分离）。
    - 单头分类器输出 Coarse 3-way 标签（Benign / DDoS / Web Attack），其中 Web Attack 将子类合并。
  - **归因公式**：
    $$
    IG_i(x) = (x_i - x'_i) \int_0^1 \frac{\partial F(x' + \alpha (x - x'))}{\partial x_i} d\alpha
    $$
    其中 $x'$ 为基线输入，$F(\cdot)$ 为模型输出。该公式用于计算每个特征对预测结果的贡献。

## 6. 主要结论与发现
- RoBERTa 与 DeBERTa 在整体准确率上均表现优异。
- 少数类 Web Attack 检测：
  - DeBERTa 宏 F1 = 0.9902, Web Attack F1 = 0.9717，性能优于 RoBERTa。
- 归因分析发现：
  - RoBERTa 倾向依赖单一显著特征（如目的端口、极端流间时间）。
  - DeBERTa 分布式依赖多种行为特征（平均流间时间、流包率、流时长等），解释更合理、泛化性更好。
- 结论：编码器型 LLM 可同时实现高精度检测与可解释性，且归因结果符合已知入侵检测原则。
