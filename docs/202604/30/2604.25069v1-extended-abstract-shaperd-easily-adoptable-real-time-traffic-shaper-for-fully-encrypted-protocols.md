## 1. 问题与背景  
随着全球范围内的网络审查逐渐加剧，许多国家在政治动荡或重要选举期间加强了互联网审查。这导致了对信息流的完全控制，从而可能严重影响公共认知。为了应对这一问题，用户依赖于各种“绕过审查”的工具，其中基于完全加密协议（FEPs）的工具因其良好的性能和安全性而被广泛采用。然而，近年来，审查者采用被动流量分析和主动探测等技术，能够有效地识别和封锁这些工具，因此亟需找到更有效的绕过检测的方法。

## 2. 核心思路 / 方法  
本文提出了一种名为Shaperd的实时流量塑形工具，旨在增强FEPs的隐匿性，抵抗审查者的检测方法。Shaperd通过实时分析数据包内容并使用创新的约束系统，允许用户生成具有特定特征的流量，灵活地调整数据包长度和时序。这一方法相较于传统的FEP工具，能够更好地应对频繁变化的检测规则，并且具有较低的性能开销。

## 3. 结果与结论  
初步测试表明，Shaperd对底层系统吞吐量的影响微乎其微，同时能够有效地避开基于数据包长度和熵值等规则的检测系统。通过这种方式，Shaperd能够与现有的FEPs无缝集成，增强其抗封锁能力，具有较强的实用性。

## 4. 局限与适用边界  
目前，Shaperd的时间控制模块仍在开发中，尚未完全实现实时的时序塑形。此外，Shaperd的填充算法目前效率较低，未来计划通过启发式方法改进。

## Abstract
Fully encrypted protocol-based tools (FEPs) are tools commonly used to circumvent censorship in restrictive regions, valued for their performance and security. However, in recent years, censors have been able to block them using an array of attacks based on passive traffic analysis and active probing. We propose Shaperd, an easily adoptable and real-time traffic shaper designed specifically to aid FEPs become more resilient to detection. Shaperd operates directly on packet contents in real time, using a novel constraint system to allow its users to generate traffic flows with any desired features. Our preliminary results reveal Shaperd introduces minimal overhead to the underlying system's throughput.

## 4. 方法详解

### 总体架构
- 输入流量 → **Shaper 线程** → **Timer 线程** → 输出流量
- 核心：**约束系统** + **实时内容塑形** + **时序控制（进行中）**

### Shaper 线程
- 监控流量缓冲区，直接检查数据包内容
- 两种塑形方法：
  1. **长度缩减**：减少数据包内容直到满足约束
  2. **内容填充**：迭代增加字节直至满足约束（当前为简单填充，未来改进为启发式）  
- 输出到 Timer 线程

### Timer 线程
- 控制数据包发送时序
- 约束包括最小/最大延迟、固定间隔、吞吐量约束
- 当前为开发中，支持实时时序塑形目标（见正文 Section 2）

### 约束系统
- 内容约束：函数 + 值 + 比较模式 + 目标数据包
- 示例：ASCII 可打印字符 ≥ 50%（见正文 Section 2）
- 时序约束：最小/最大延迟、间隔、抖动等 [开发中]

### 公式示例（约束函数）
$$
\text{constraint}(p) = f(p) \; \text{op} \; v, \quad p \in \text{target packets}
$$
其中 $f(p)$ 为可计算的度量函数，op 为比较操作符，v 为约束值。

## 6. 局限性与风险
- **假设约束**：仅支持可计算函数约束，非可计算特征无法处理
- **应用边界**：当前仅支持 TCP 协议，时序控制模块尚未完成
- **潜在风险**：简单填充可能导致性能下降，对复杂约束扩展能力有限
