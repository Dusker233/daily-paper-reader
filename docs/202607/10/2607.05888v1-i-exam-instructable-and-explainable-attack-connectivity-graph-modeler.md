## 1. 问题与背景
大型网络系统的安全管理面临复杂性挑战，单个组件的修改可能显著影响整体安全态势与系统功能可用性。论文关注如何帮助系统管理员分析网络攻击路径、评估安全风险，并制定不会破坏服务连通性的网络加固策略。传统攻击图方法难以同时推理攻击行为和网络功能约束，因此论文基于 Attack Connectivity Graph（ACG）和自动规划技术探索更系统化的安全分析方案。

## 2. 核心思路 / 方法
论文提出 i-EXAM（Instructable and Explainable Attack Connectivity Graph Modeler），一种结合 AI 规划与大语言模型的交互式网络安全分析工具。该方法将网络资产、漏洞信息和连接关系转换为 JSON 数据库，再通过 PDDL 生成规划模型，利用规划器寻找攻击路径、计算安全指标并生成加固方案。i-EXAM 使用 Fast-Downward 的 A* 搜索与 LMCut 启发式算法优化攻击难度分析，并通过多样化方案选择提供多个网络修改策略。进一步地，论文利用 Llama-3.1-Nemotron-70B-Instruct 将规划失败信息和反事实分析结果转换为自然语言解释，使管理员无需掌握 AI 规划知识即可理解安全建议。

## 3. 结果与结论
论文展示了 i-EXAM 在测试网络中的应用案例，系统能够根据目标节点生成攻击计划，并针对不可渗透性指标和攻击难度指标提出不同网络加固方案。实验结果表明，在 30 节点规模网络上的评估中，启发式搜索可使计算时间降低约 50%，同时规划方法能够保证攻击路径分析和加固方案生成的正确性。论文认为，将形式化 AI 规划与 LLM 解释能力结合，可以提升网络安全分析工具的可解释性和实际部署价值。

## 4. 局限与适用边界
论文主要局限在于当前评估规模集中于较小网络，针对更大规模企业网络的扩展能力仍需进一步验证。此外，未来工作还需要研究更准确的加固成本函数，并通过领域专家开展可用性研究。该方法适用于具有明确网络配置、漏洞信息和安全目标的网络环境。

## Abstract
i-EXAM is a planning-powered tool that helps system administrators to create security profiles of complex networks and perform what-if analyses to identify network hardening strategies. It leverages planning compilation that provides soundness and completeness guarantees to identify attack paths, evaluate security metrics, generate diverse hardening strategies, and explain these strategies in natural language using Large Language Models.
