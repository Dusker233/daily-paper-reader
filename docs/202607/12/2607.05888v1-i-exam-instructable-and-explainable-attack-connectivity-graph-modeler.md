## 1. 问题与背景
大型网络环境中的安全管理面临复杂性挑战，单个组件的修改可能对整体安全态势和系统韧性产生巨大影响。传统安全分析方法难以同时考虑攻击路径、网络连通性以及服务功能保持之间的关系，因此需要一种能够帮助系统管理员理解攻击风险并制定加固策略的方法。论文关注如何利用人工智能规划技术和可解释模型提升复杂网络的安全评估与防御决策能力。

## 2. 核心思路 / 方法
论文提出 i-EXAM（Instructable and Explainable Attack Connectivity Graph Modeler），一个基于 SPEAR 框架的交互式网络安全分析工具，将攻击连接图（Attack Connectivity Graph, ACG）编译为 PDDL 规划问题，并利用 AI 规划器进行攻击路径分析和安全加固推理。该方法通过 Nmap、Wazuh、OpenVAS 等工具收集主机、网络配置和漏洞信息，将数据转换为 JSON 数据库，再自动生成规划模型。i-EXAM 使用规划搜索计算攻击路径、评估不可渗透性指标（M1）和攻击难度指标（M2），并通过多样化方案生成机制提供不同网络加固策略。与传统攻击图方法相比，其创新在于同时考虑攻击行为与网络功能连通性，并结合 Llama-3.1-Nemotron-70B-Instruct 大语言模型，将规划结果和反事实分析转换为自然语言解释。

## 3. 结果与结论
论文展示了 i-EXAM 在测试网络中的实例化效果，系统能够可视化网络结构、识别潜在攻击路径，并根据不同安全指标生成加固方案和解释。实验结果表明，在 30 个节点规模的网络评估中，Fast Downward 结合 LMCut 启发式搜索能够将计算时间降低约 50%，同时支持多种攻击路径枚举。论文认为，将形式化 AI 规划与大语言模型解释能力结合，可以使基于规划的网络安全分析更加适用于实际系统管理员使用。

## 4. 局限与适用边界
论文主要局限在于当前评估规模仍集中于有限规模网络，针对更大规模企业网络的扩展能力仍需进一步验证。从现有文本无法确认其在真实生产环境中的长期部署效果，未来工作包括学习型加固成本函数、专家可用性研究以及更大规模网络扩展。

## Abstract
i-EXAM is a planning-powered tool that helps system administrators to create security profiles of complex networks and perform what-if analyses to identify network hardening strategies. It leverages planning compilation that provides soundness and completeness guarantees to identify attack paths, evaluate security metrics, generate diverse hardening strategies, and explain these strategies in natural language using Large Language Models.
