## 1. 问题与背景

论文关注的是：如何让大语言模型（LLM）真正安全地参与自动化网络防御，而不是仅仅生成“看起来合理”的安全建议。作者指出，当前 SOC（安全运营中心）长期面临高告警压力、人工响应瓶颈以及攻击者响应速度快于人工处置的问题，DarkSide 与 Colonial Pipeline 等事件说明了延迟响应的实际代价。现有基于 LLM 的方案往往允许模型直接生成可执行动作，或者将自然语言解析为网络控制命令，这会带来严重安全风险。论文因此试图回答一个更底层的问题：如何在“LLM 推理”与“真实防御执行”之间建立一个可验证、可约束、可追责的系统边界。

## 2. 核心思路 / 方法

论文提出了 PocketAgents，一个“manifest-driven（清单驱动）”的自治防御代理库。每个代理不是通过编写框架代码实现，而是由三个静态数据文件组成：manifest（能力与约束声明）、prompt（调查逻辑）以及 context（环境上下文）。系统运行时由统一 dispatcher 调度代理，并通过受限 telemetry 接口向代理暴露有限证据；代理只能输出符合 schema 的结构化报告，而所有动作必须先通过 manifest 定义的类型校验与动作白名单验证后，才能进入 enforcement adapter 执行。

其核心创新在于把“调查”“验证”“执行”三层显式分离：LLM 只负责概率性调查，runtime 负责确定性验证，执行器只接受经过验证的结构化动作。论文还定义了形式化 admission predicate，用于检查报告结构是否合法、动作是否在允许目录内、以及目标实体是否真实存在于本次 telemetry 中。相比传统 prompt-based 安全实验只评估“模型是否能描述攻击”，PocketAgents 重点评估“自治调查是否能安全跨越执行边界”，从而使失败原因能够被归因到 schema、grounding、validation 等明确类别，而不是笼统归因为“模型失误”。

## 3. 结果与结论

作者在 Perry 网络欺骗测试床上实现了 PocketAgents，并构建了两个代理：Command and Control（C2）与 Exfiltration，对应 MITRE ATT&CK 中不同战术类别。实验共进行了 18 次闭环 DarkSide 风格攻击测试，其中 13 次成功生成经过验证的 network-block 动作并成功遏制攻击，4 次因 schema 校验失败被 runtime 拒绝，1 次生成了合法但“不采取动作”的结果。

论文据此认为，类型化 enforcement boundary 能够把 LLM 驱动的防御行为转化为“可测量、可扩展、可归因”的系统行为。作者强调，真正重要的并不是模型能否识别攻击，而是系统是否能够安全地决定“哪些识别结果允许进入真实执行层”。

## 4. 局限与适用边界

论文明确说明，其实验只覆盖 defender-controlled 环境，并假设 dispatcher、manifest、validation code 与 enforcement adapter 都可信。Prompt injection、memory poisoning、恶意日志、LLM provider 被攻击、false positive 控制等现实问题均未纳入实验范围。当前实现中 grounding check 也并未完全在线强制执行，而是在运行后基于 query trace 进行验证，因此系统的完整实时安全性从现有文本无法确认。

## Abstract
Connecting large language models (LLMs) to defensive enforcement requires more than asking a model whether an attack is happening. A defender must decide which model outputs may change the system state, which outputs must be rejected, and how failures should be recorded. We present PocketAgents, a manifest-driven library of autonomous defense agents. Each agent is installed as three data files: a manifest, a prompt, and a runtime context. The shared runtime gives the agent bounded telemetry access and accepts only typed reports whose requested action appears in the manifest. We implemented PocketAgents on top of a cyber arena (Perry), a cyber-deception testbed, and evaluated two agents, Command and Control and Exfiltration, in 18 closed-loop trials of a DarkSide-inspired attack on a small enterprise topology. Thirteen trials produced validated network-block actions and contained the attack; four failed schema validation; one produced a valid no-action decision. The experiments show that a typed boundary makes LLM-driven defense measurable, extensible, and attributable.
