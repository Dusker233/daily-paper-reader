## 1. 问题与背景

论文关注的是大语言模型（LLM）驱动的网络安全智能体如何在真实攻防任务中实现“在线自我进化”。现有网络安全 Agent 虽然已经被用于 CTF、漏洞利用和渗透测试等任务，但大多依赖固定的人工设计 scaffold（提示词、工具链和工作流），难以适应不同目标环境中的失败模式与攻击路径。作者认为，相比代码生成任务，网络安全任务具有目标异构性强、验证反馈明确、单次成功价值高等特点，因此特别适合基于执行经验进行 on-policy 自我演化。问题的重要性在于，如果 Agent 能够根据失败轨迹持续调整自身策略，就可能在复杂安全场景中形成真正具有适应性的自动化攻击与测试能力。

## 2. 核心思路 / 方法

论文提出了 CyberEvolver，一个面向网络安全任务的结构化自进化框架，其核心思想是在多轮失败执行后，自动修改 Agent 自身的 scaffold，而不是仅仅重复采样。为解决网络安全场景中的“变异空间无结构”“环境反馈噪声大”“持续演化容易退化”三类问题，作者设计了四层可演化 Agent 架构，将 scaffold 拆解为可局部修改的结构化组件；同时引入 trace-to-diagnosis 机制，把复杂执行日志转化为可操作的诊断信号，用于指导后续 mutation。为了避免单一路径不断累积错误，CyberEvolver 还采用基于 population 的 beam search，在每一代保留多个变体并并行探索不同演化方向。与已有方法相比，它不仅支持对 exploit script、payload、工具调用等执行级组件进行修改，还能在缺乏明确测试反馈的对抗环境中持续完成有效自改进。

## 3. 结果与结论

实验覆盖 CTF、漏洞利用和渗透测试三类任务，并在 Kimi-K2.5、MiniMax-M2.5、DeepSeek-V3.1 与 Qwen3-235B-A35B-Instruct-2507 四种开源模型上进行评估。结果显示，CyberEvolver 相比初始 seed agent 平均提升了 13.6% 的成功率，并持续优于六种人工设计的安全 Agent 框架以及 ACE、HGM 等已有自改进方法。论文中特别展示了一个高难度 blind SQL injection CTF 挑战：初始 Agent 无法发现 cookie 中隐藏的 oracle，并在错误路径上耗尽预算，而演化到第三代后，系统已经能够自动识别布尔盲注通道、使用二分搜索提取管理员凭证，并最终成功获取 flag。作者据此认为，结构化 scaffold self-evolution 是构建自适应网络安全 Agent 的有效方向。

## 4. 局限与适用边界

从现有文本来看，论文主要验证了在安全测试与攻击任务中的在线自进化能力，但对于长期稳定性、跨任务泛化能力以及真实生产环境中的安全风险控制尚未充分展开。该方法依赖可执行验证信号（如 flag、shell 或 exploit 成功），因此更适用于反馈明确的网络安全环境，而未必适用于难以自动验证的开放式推理任务。此外，论文没有充分说明演化过程中的计算开销与资源成本。

## Abstract
LLM-based agents are increasingly used for cybersecurity tasks, but most existing systems rely on fixed, human-designed scaffolds that struggle to adapt across diverse targets and failure modes. We introduce \textsc{CyberEvolver}, a self-evolving cybersecurity agent framework that iteratively revises its own scaffold based on experience from failed execution attempts. Self-evolution in cybersecurity is challenging because the space of possible scaffold changes is largely unstructured, execution feedback is sparse and often obscured by the environment, and low-diversity updates can cause errors to compound over repeated iterations. \textsc{CyberEvolver} addresses these challenges with a four-layer evolvable agent architecture that decomposes scaffold optimization into structured components, a trace-to-diagnosis mechanism that converts noisy execution logs into actionable revision signals, and a population-based beam search strategy that preserves diverse agent variants during evolution. We evaluate \textsc{CyberEvolver} on CTF challenges, vulnerability exploitation, and penetration-testing tasks using four open-source LLMs. Across these settings, \textsc{CyberEvolver} improves the seed agent's success rate by $13.6$\,\% on average, and outperforms six human-designed cybersecurity agents as well as two self-improvement methods adapted from other domains. These results suggest that scaffold self-evolution is a promising direction for building adaptive LLM agents for security testing.

## 4. 方法详解

### 4.1 四层可演化 Agent 架构

论文定义 Agent 为：

$$A = (L_S, L_I, L_P, L_D)$$

其中四层分别对应：

- **Strategy Layer \(L_S\)**：总体攻击策略与任务规划。
- **Environment Interface \(L_I\)**：与目标环境交互的规则、工具调用方式、协议约束。
- **Perception Layer \(L_P\)**：观察结果解析、日志理解、状态抽取。
- **Domain Knowledge \(L_D\)**：技能库、payload、exploit script、领域知识模块。

这种拆分避免一次性重写整个 scaffold，使 mutation 能更局部、更可控，见正文 Section 2.1 / Figure 2。

### 4.2 Trace-to-Diagnosis

执行 Agent 得到轨迹：

$$A \xrightarrow{C} \tau$$

之后系统将轨迹压缩为摘要 \(z\)，再生成诊断报告 \(d\) 和进展分数 \(s\)。该机制的作用是把原始 noisy execution logs 转化为“哪一层该改、为什么改、怎么改”的结构化信号，见正文 Section 2.2。

### 4.3 Population-based Beam Search

每一代维护一个 population \(P_t\)，选择 top-K 高分变体作为父节点，再生成多个 child variants。这样可以避免单一路径自进化把错误策略越强化越严重，同时保留多种攻击假设，见正文 Section 2.3。

### 4.4 Mutation Operator

论文形式化为：

$$\mathrm{MUTATE}(A, d, z) \rightarrow A'$$

即根据诊断报告和压缩轨迹，修改一个或多个 scaffold 层，生成新 Agent \(A'\)。

## 6. 局限性与风险

- **假设约束**：方法依赖明确成功验证信号，如 flag、shell、exploit success；对于开放式、无自动 verifier 的安全分析任务，效果可能下降。
- **应用边界**：实验主要在 benchmark 和受控环境中完成，真实企业网络、多租户环境或长周期攻防任务中的稳定性仍需验证。
- **成本问题**：多代、多分支 beam search 会带来更高 token、时间和执行资源成本，具体部署成本需结合 Table 11 / Table 12 评估。
- **安全风险**：该框架能提升自动化漏洞利用能力，属于明显双用技术；是否有发布限制、访问控制或滥用防护需要进一步核查。
- **泛化风险**：on-policy evolution 强调针对单个目标优化，跨任务迁移能力不一定优于 off-policy 经验积累方法。
