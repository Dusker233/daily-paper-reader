## 1. 问题与背景

论文研究检索增强生成（RAG）系统中的知识投毒（Knowledge Poisoning）问题，特别关注 Confundo 这类能够穿透预处理、重排序和改写环节的高级投毒攻击。作者指出，现有防御普遍假设“只要识别出可疑证据，就能避免受到影响”，但实验发现模型即使能够察觉证据矛盾或不可信，最终仍可能生成并采纳被投毒的信息。由于这种“监控—控制鸿沟（monitoring-control gap）”的存在，问题本质并非单纯的检测问题，而是信息流控制问题，因此需要从系统架构层面限制不可信信息对最终生成行为的影响。

## 2. 核心思路 / 方法

论文提出 Cordon Principle（警戒线原则）：任何能够执行最终自然语言生成的模块都不应直接访问未经信任的自然语言证据。基于这一原则，作者设计了多智能体框架 CORDON-MAS，将证据处理拆分为 Extractor、Auditor、Gate 和 Synthesizer 四个角色，并通过不对称内存权限实现信息隔离。Extractor 是唯一能够读取原始文档的组件，其职责是将文本转换为结构化 Claim Card；Auditor 基于跨来源一致性和边际影响力计算风险分数，对声明进行审核；Gate 进行独立的可回答性判断；Synthesizer 仅能访问通过认证的结构化声明而无法接触原始文本。与已有方法主要依赖过滤、异常检测或文档隔离不同，该方法创新地将防御重点从“识别恶意内容”转向“控制信息流拓扑结构”，从架构上切断投毒文本对最终生成器的直接控制路径。

## 3. 结果与结论

在五个 BEIR 数据集上，CORDON-MAS 相比未防护的 Vanilla RAG 将攻击成功率（ASR）从 27.5% 降至 2.1%，相对降低约 92.4%。消融实验表明 Auditor 是最关键组件，移除后 ASR 会增加 4 至 16 倍，而多文档一致性串谋（多个投毒文档彼此一致）构成当前体系最主要的安全边界。进一步引入基于参数知识的事实合理性检查后，SciFact 数据集上的 ASR 从基础 Auditor 的 46.9% 降至 26.5%。论文最终认为，RAG 投毒防御应被重新理解为信息流控制问题，而非单纯的内容检测问题。

## 4. 局限与适用边界

论文明确指出 CORDON-MAS 并未彻底解决所有检索投毒问题。当多个投毒文档彼此一致且形成协调攻击时，仅依赖跨文档一致性审核会失效，因此作者额外引入了事实合理性检查进行补强。该方法主要保护“未经信任的自然语言证据直接影响最终生成器”这一攻击路径，对于其他类型攻击或更广泛的系统安全问题，从现有文本无法确认其防御能力。

## Abstract
Retrieval-augmented generation (RAG) increasingly underpins high-stakes applications, yet remains vulnerable to Confundo-style poisoning where adversarially optimized documents manipulate generated outputs. Existing defenses assume that detecting poisoned evidence prevents harm. We show this assumption is incorrect: models exhibit a monitoring-control gap -- they can detect contradictions in retrieved evidence yet still act on poisoned claims. We introduce the Cordon Principle -- no agent capable of final synthesis may access untrusted natural-language evidence -- and realize it through CORDON-MAS, a compartmentalized framework that enforces this principle architecturally by separating evidence extraction, cross-source audit, and answer synthesis into agents with asymmetric memory privileges. Across five BEIR datasets, CORDON-MAS reduces attack success rate by 92.4\% relative to undefended RAG. This reframes RAG poisoning from a detection problem to an information-flow control problem.
