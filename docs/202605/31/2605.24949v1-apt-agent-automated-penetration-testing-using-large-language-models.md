## 1. 问题与背景

论文关注如何利用大语言模型（LLM）实现自动化渗透测试，以缓解传统人工渗透测试在规模化环境下面临的专家依赖、效率不足和认知负担问题。尽管已有研究开始将LLM引入渗透测试流程，但仍存在两个关键障碍：一是模型会幻觉生成错误的技术实体（如Metasploit模块路径、命令参数和载荷名称），二是在多阶段攻击过程中难以维持长期上下文记忆。由于渗透测试高度依赖精确命令和持续状态跟踪，这些问题会直接降低自动化系统的可靠性和成功率。

## 2. 核心思路 / 方法

论文提出APT-Agent，一个面向渗透测试的全自动LLM驱动框架，能够自主完成侦察（Reconnaissance）、利用（Exploitation）以及后渗透与数据获取（Exfiltration）流程。为解决技术实体幻觉问题，系统设计了混合纠错模块，通过RapidFuzz模糊匹配和后缀精确匹配相结合的方式，将LLM生成的错误模块名称或命令修正为合法的Metasploit模块。为解决长期上下文丢失问题，作者提出阶段感知的上下文管理模块（Context Management Module, CMM），持续记录当前状态、历史命令及执行结果，并将这些信息注入后续提示词。与仅依赖对话上下文的现有方案相比，该方法能够避免重复失败操作，并根据历史结果动态调整攻击策略，从而提升多步骤攻击任务的稳定性。

## 3. 结果与结论

作者在Metasploitable 2环境中对七类存在漏洞的服务进行了评估，覆盖Web、数据库和网络协议场景。实验结果显示，APT-Agent的端到端利用成功率达到84.29%，显著高于Script Kiddie的48.57%和PentestGPT的18.57%。实验日志还表明，系统能够在利用失败后通过纠错与恢复机制自动切换攻击路径，并最终建立会话和完成目标数据获取。论文认为，结合命令纠错机制与长期状态管理机制，可以显著提升LLM自动化渗透测试的可靠性、自动化程度和任务完成率。

## 4. 局限与适用边界

从现有文本可确认，实验主要在Metasploitable 2环境及七个已知脆弱服务上开展，因此其在真实复杂企业网络、未知漏洞场景以及大规模目标环境中的泛化能力仍有待进一步验证。论文附录还指出，该系统是以攻击目标完成为导向的自动化红队框架，而非以漏洞覆盖率最大化为目标，因此并不适用于需要全面漏洞发现和修复建议生成的场景。

## Abstract
Penetration testing is essential to securing modern web infrastructures, yet traditional manual methods struggle to keep pace with their scale and complexity. Large Language Models (LLMs) offer new opportunities for automating these tasks, but existing approaches face two persistent challenges: hallucination of technical entities and insufficient long-term contextual memory. To address these issues, we present APT-Agent, a fully automated LLM-driven penetration testing framework that systematically orchestrates reconnaissance, exploitation, and exfiltration. APT-Agent introduces a hybrid rectification module to recover hallucinated commands and a command-specific memory architecture to preserve operational context across multi-step attack sequences. We evaluate our APT-Agent on Metasploitable 2 against seven vulnerable services spanning web, database, and network protocols. APT-Agent achieves an 84.29% end-to-end exploitation success rate, compared to 48.57% (Script Kiddie) and 18.57% (PentestGPT) under matched conditions. By reducing cognitive burden and minimizing reliance on human intervention, APT-Agent represents a step toward scalable, reliable, and cognitively efficient automation for penetration testing.

## 4. 方法详解

### 总体架构
APT-Agent 包括三阶段流程：侦察 (Reconnaissance) → 利用 (Exploitation) → 后渗透/数据获取 (Exfiltration) (见 Figure 6)。

### 1. 混合命令纠错模块（Hybrid Rectification Module）
- 目标：修正 LLM 输出的错误 Metasploit 模块路径和命令。  
- 设计：
  - **RapidFuzz 模糊匹配**：对模块路径末段进行相似度匹配。  
  - **精确后缀匹配**：确保最终可执行命令与合法模块一致。  
- 功能效果：减少执行失败与非法操作风险 (见 Section II)。

### 2. 阶段感知上下文管理模块（Context Management Module, CMM）
- 目标：维护多阶段攻击的历史状态和执行结果。  
- 功能：
  - 记录每次迭代的命令、结果和关键发现。  
  - 将历史信息注入后续 LLM 提示，实现策略动态调整。  
- 效果：防止重复尝试，提高长程任务成功率 (见 Section II / Figure 2)。
