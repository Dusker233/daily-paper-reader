## 1. 问题与背景

论文研究的是多智能体大语言模型（LLM-MAS）在存在 Byzantine 故障时的鲁棒协作问题，即部分代理可能因幻觉、推理错误或恶意攻击而传播错误信息，进而污染整个系统的推理结果。作者指出，当前多智能体 LLM 越来越依赖 agent 之间的对话与协同，但现有方法通常默认节点会诚实汇报置信度，或者依赖中心化 leader 协调，因此在真实对抗环境下容易被操纵。论文将这一问题与经典 Byzantine 共识理论联系起来，强调核心挑战在于：代理应如何判断邻居信息是否可信，以及通信拓扑应如何设计才能限制恶意节点的影响。

## 2. 核心思路 / 方法

论文提出了 Self-Anchored Consensus（SAC）方法，这是一个完全去中心化的“过滤—修正”迭代协议。每个 agent 在每轮中都会接收邻居回复，并基于自身独立评估而非发送方自报置信度，对邻居消息进行可信度判断，再过滤掉可疑信息，并据此重新生成自己的答案。方法设计借鉴了 Byzantine 鲁棒共识中的 Mean-Subsequence-Reduced（MSR）思想，通过局部筛选机制削弱恶意节点影响，同时利用 re-prompting 完成自然语言层面的响应更新。除此之外，论文还引入 r-robustness 与 (F+1)-robustness 等图论条件，用于分析在何种通信拓扑下，诚实 agent 能持续传播可靠信息并抑制 Byzantine 影响。相比已有 CP-WBFT、Trusted MultiLLMN 和 DecentLLMs 等方法，SAC 不依赖 leader、不要求全连接 evaluator-worker 图，也避免了对 self-reported confidence 的脆弱假设。

## 3. 结果与结论

论文在数学推理与常识推理任务上进行了实验，包括 Commonsense170k 等 benchmark，并比较了不同通信拓扑下的方法表现。结果表明，在存在 Byzantine agent 的情况下，SAC 能持续保持较高性能，并有效抑制错误信息传播；而已有基线方法在某些拓扑结构中会出现明显性能崩溃，甚至比不协作时更差。作者据此认为，LLM 多智能体系统的鲁棒性不仅取决于推理能力本身，还高度依赖通信结构与信息聚合机制，而经典 Byzantine-resilient consensus 理论可以为 LLM-MAS 提供有效的结构化设计原则。

## 4. 局限与适用边界

从现有文本来看，论文主要针对“存在客观正确答案”的任务场景，例如数学与常识推理，因此其方法是否适用于开放式生成、创造性写作或主观偏好任务尚无法确认。论文也主要分析了静态通信图与有界 Byzantine 数量条件下的情况，对于动态网络、大规模异构 agent 或更复杂攻击方式的适应性，现有文本没有给出充分说明。

## Abstract
Large language model (LLM) agents increasingly collaborate over peer-to-peer networks to improve their reliability. However, these same interactions can also become a source of vulnerability, as unreliable or Byzantine agents may sway neighboring agents toward incorrect conclusions and degrade overall system performance. Existing methods rely on leader-based coordination or self-reported confidence, both of which are susceptible to adversarial manipulation. We study decentralized LLM multi-agent systems (LLM-MAS) and propose Self-Anchored Consensus (SAC), a fully decentralized iterative filter-and-refine protocol in which agents iteratively exchange responses, locally evaluate and filter unreliable messages, and refine their own outputs. We present $(F{+}1)$-robustness conditions for the communication graph that ensure honest agents preserve and propagate reliable information despite Byzantine influence. Experiments on mathematical and commonsense reasoning benchmarks show that SAC effectively suppresses Byzantine influence and consistently improves performance across diverse communication topologies, whereas prior methods degrade under adversarial conditions.

## 4. 方法详解

### 4.1 系统与威胁模型
- LLM-MAS，节点集合 $V$，拜占庭节点 $B=F \cup A$，可靠节点 $P=V\setminus B$（见 Section 3.1-3.2）。  
- 通信图 $G=(V,E)$，每轮节点 $i$ 与邻居 $N_i$ 交换回复 $r_i^{(t)}$。  
- 采用 $F$-local 模型限制每个可靠节点邻居中的拜占庭节点数量（Definition 3.2）。

### 4.2 Self-Anchored Consensus (SAC)
- **核心迭代公式**：
$$
r_i^{(t+1)} = \text{Refine}\Big( r_i^{(t)}, \text{Filter}(\{r_j^{(t)} : j \in N_i\}) \Big)
$$
- **模块**：
  - **Filter**：局部筛选邻居消息，剔除低接收端置信度或可疑回答。
  - **Refine / Re-prompting**：基于过滤后的邻居消息更新自身回答。
- **图论保证**：
  - $(F+1)$-robustness: 诚实节点可持续传播可靠信息（Section 3.3 / Lemma 3.5）。
