## 1. 问题与背景
本文研究的核心问题是中小企业（SMBs）在日益增长的网络安全威胁下缺乏资源建立完整的安全运营中心（SOC）或部署企业级检测平台，导致平均检测时间远超大型企业。背景在于大型语言模型（LLMs）在技术文本上预训练，具备潜在安全知识，而参数高效微调技术可让小模型在低计算成本下适应特定领域。解决这一问题能够显著缩小中小企业与大型企业之间的安全能力差距，提高威胁检测效率。

## 2. 核心思路 / 方法
论文提出了 OpenSOC-AI 框架，基于 TinyLlama-1.1B 模型，通过 LoRA（低秩适配）微调，仅使用 12.6M 可训练参数，对 450 条领域特定安全日志进行训练，实现威胁分类、MITRE ATT&CK 技术映射和严重性评估。方法创新在于利用参数高效微调和小型模型处理结构化日志特征，能够在单块 NVIDIA T4 GPU 上不到五分钟完成训练，相比传统大模型方法无需昂贵 API 或大规模算力即可部署。

## 3. 结果与结论
实验结果显示，微调模型在 50 条评估示例上威胁分类准确率提升至 68%，严重性分类提升至 58%，F1 分数达到 0.68。结论表明，参数高效微调小型 LLM 可显著提升中小企业的安全日志分析能力，实现快速、可复现且低成本的威胁检测。

## 4. 局限与适用边界
论文局限在于训练数据仅包含合成和公开日志，未使用真实用户数据或生产系统信息，因此结果在真实环境中的泛化能力尚需验证。适用边界主要是资源受限的中小企业或需要本地部署的小型 SOC 环境。

## Abstract
Small and medium sized businesses (SMBs) face an escalating cybersecurity threat landscape, yet most lack the resources to staff full Security Operations Centers (SOCs) or deploy enterprise grade detection platforms. This paper presents OpenSOC-AI, a lightweight log analysis framework that uses parameter efficient fine tuning of a 1.1-billion parameter language model (TinyLlama-1.1B) to perform automated threat classification, MITRE ATT&CK technique mapping, and severity assessment on raw security log entries. Using Low-Rank Adaptation (LoRA) with only 12.6 million trainable parameters (roughly 1.13% of the base model), we fine tuned on 450 domain specific SOC examples in under five minutes on a single NVIDIA T4 GPU. Testing on a heldout set of 50 examples showed a 68% point gain in threat classification accuracy (from 0% to 68%), a 30% point gain in severity accuracy (from 28% to 58%), and an F1 score of 0.68 compared to the untuned baseline. Full codebase, adapter weights, and datasets are publicly released to support reproducibility and community extension.

## 4. 方法详解

### 基础模型选择
- TinyLlama-1.1B-Chat-v1.0  
  - 参数量 1.1B，适合 4-bit 量化  
  - Chat-tuned，支持 instruction-following  
  - Apache 2.0 许可，允许自由使用  

### 数据集构建
- 500 条安全日志示例（450 训练 + 50 评估）  
- 格式：Alpaca instruction style  
- 输出字段：THREAT TYPE、MITRE ID、SEVERITY、RISK SCORE、EVIDENCE、RECOMMENDATION  
- 12 类威胁覆盖（见正文 Section III-B / Table I）  

### 系统架构
- 原始日志 → instruction prompt → 微调 TinyLlama → 解析为六字段结构化输出（见 Fig.1）  

### LoRA 微调配置
- LoRA rank $r=16$，$\alpha=32$，dropout $=0.05$  
- 目标模块：q, k, v, o, gate, up, down  
- 优化器：paged AdamW 8-bit  
- 学习率：$2 \times 10^{-4}$，cosine schedule + 5% warmup  
- Epochs: 3，batch size effective 16  
- 训练时长：4 分 21 秒，单张 T4 GPU  
- 参数占比：12.6M / 1.112B ≈ 1.13%
