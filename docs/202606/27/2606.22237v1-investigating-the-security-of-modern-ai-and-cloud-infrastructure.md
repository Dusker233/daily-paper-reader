## 1. 问题与背景  
本文关注现代 AI（尤其是深度神经网络与大语言模型）以及云基础设施在真实部署中的安全性问题。作者指出当前研究往往将攻击面割裂处理，缺乏一个统一框架来解释物理层、架构层与算法层漏洞如何在整个 AI 技术栈中交互。其核心动机是质疑“模型与环境天然隔离”的安全假设是否成立。该问题重要性在于，LLM 与云服务已广泛用于关键系统，一旦隔离假设失效，攻击可能跨层传播并影响多个安全边界。

## 2. 核心思路 / 方法  
论文提出一种按“交互层级”划分的威胁模型，从共享内存访问、共享硬件资源访问到仅通过服务接口访问逐层递进分析攻击能力。基于该框架，作者系统展示不同层级下的攻击方式，例如通过共享内存侧信道泄露用户 token 与 API key、对 GGUF 模型进行故障注入以诱导越狱输出。进一步在仅共享硬件资源场景下，利用 Rowhammer 等内存攻击影响栈、寄存器与程序执行流程，并讨论绕过 TLS、PQC 签名与认证系统等机制。最后在仅服务访问条件下，利用对抗性 suffix 实现对 LLM 与 guard 模型的联合绕过，从而证明即使强防护仍可能被输入攻击突破。

## 3. 结果与结论  
实验结果表明，在共享内存条件下可以实现敏感 token 与 API key 的泄露，并在特定模型环境中触发越狱行为。在仅共享硬件资源的情况下，可以通过内存翻转与故障注入影响程序执行路径，甚至干扰认证与安全检查流程。在仅服务访问条件下，对抗性输入仍可成功绕过对齐机制与安全 guard，实现模型输出控制。整体结论认为现代 AI 与云系统的安全性高度依赖于跨层隔离假设，而这一假设在多种现实攻击下可能失效。

## 4. 局限与适用边界  
从现有文本无法完整确认该研究在实际工业环境中的可复现性与攻击成本边界，例如部分攻击可能依赖特定硬件条件或实验设置。其威胁模型虽然覆盖多个层级，但不同攻击之间的现实发生概率与前提条件差异较大。整体上，该框架更偏向系统性攻击面分析与概念验证，适用于安全研究与威胁建模，而非直接等价于普适现实攻击能力。

## Abstract
The widespread deployment of Deep Neural Networks and Large Language Models (LLMs) relies on a foundational assumption of isolation that this dissertation challenges. This work systematically deconstructs security assumptions around AI and modern cloud infrastructure through a taxonomy of interaction levels that ranges from physical memory co-location to remote service interfaces. While significant research has addressed individual attack surfaces in isolation, the security community lacks a unified framework for reasoning about how physical, architectural, and algorithmic vulnerabilities manifest across the modern AI stack. This dissertation addresses that gap by demonstrating practical attacks that exploit assumptions at each layer of abstraction.
