## 1. 问题与背景

大语言模型推理广泛依赖 KV Cache 来复用前缀计算，但随着模型规模和上下文长度不断增长，GPU 显存容量成为 KV Cache 的主要瓶颈，缓存管理策略直接影响推理延迟和系统吞吐。现有主流框架（如 vLLM）普遍采用 LRU（最近最少使用）淘汰策略，但真实工作负载同时具有时间局部性和访问频率等复杂特征，不同类型请求容易相互冲刷缓存，降低缓存命中率。因此，论文希望设计一种能够根据工作负载动态适应的 KV Cache 管理机制，以更有效利用有限缓存空间。

## 2. 核心思路 / 方法

论文将自适应缓存算法 ARC（Adaptive Replacement Cache）集成到 vLLM 的 KV Cache 管理模块，用于替代传统 LRU 淘汰策略。该方法将缓存逻辑划分为“近期访问”和“高频访问”两类队列，首次访问的数据保留在低频队列，多次命中的数据则提升至高频队列，从而同时利用时间局部性和访问频率信息。与此同时，方法引入 Ghost Cache，仅保存已淘汰块的元数据，根据这些历史信息动态调整两类缓存所占比例，使缓存空间能够随工作负载变化自动适配。论文强调该方案仅修改 GPU 内存管理中的淘汰模块，因此能够适用于多 GPU、协同缓存及复杂推理服务框架，而无需改变整体服务架构。

## 3. 结果与结论

实验覆盖长上下文文档问答和真实对话两类工作负载。在文档问答场景中，相较于原始 vLLM，方法最高将 KV Cache 命中率提升 10.8%，首次生成 Token 时间（TTFT）降低 12.6%；在真实对话场景中，命中率和 TTFT 分别提升约 2.1% 和 2.0%。论文认为，自适应结合访问时间和访问频率的信息，比单纯依赖最近访问的 LRU 更能适应多样化推理负载，同时具有较好的可解释性，并能够推广到批量推理场景。

## 4. 局限与适用边界

论文主要验证了文档问答和多轮对话两类工作负载，对于更多应用场景或其他缓存管理体系下的效果，从现有文本无法确认。实验主要基于将 ARC 集成到 vLLM 的 KV Cache 淘汰模块，因此其收益依赖于存在跨请求前缀复用和 KV Cache 可重用性的推理场景。

## Abstract
Key-value (KV) caching is a powerful technique for accelerating large language model inference and generation. Inference workloads are large and diverse, which makes them difficult to cache effectively. Existing cache management strategies adopt the least-recently-used policy for evicting cache blocks. However, LRU leads to multiple unrelated workloads flushing each other's caches. To address this, we integrate adaptive caching that dynamically allocates cache space between recently and frequently occurring KV blocks. Evaluations show that it improves the KV cache hit rate by up to 10.8% and reduces time to first token by up to 12.6% over naive vLLM on synthetic document question answering workloads, and 2.1% and 2.0% respectively on real-world conversation workloads. The method generalizes well to batch inference and demonstrates clear interpretability while effectively accommodating diverse workloads.
