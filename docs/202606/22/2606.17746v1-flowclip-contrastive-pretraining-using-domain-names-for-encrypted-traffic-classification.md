## 1. 问题与背景  
研究聚焦于加密网络流量分类问题，即在TLS/QUIC等加密环境下识别网站或应用流量。由于端口动态分配、深度包检测失效以及内容加密，传统基于端口或payload的方法在真实网络中逐渐不可用。即使域名与IP在一定程度上可作为标识，也会因CDN、DNS over HTTPS以及Encrypted Client Hello等机制而变得不可见或不稳定，因此需要学习更具泛化能力的流量表示。

## 2. 核心思路 / 方法  
论文提出FlowCLIP，一个基于对比学习的预训练框架，用于从加密流量中预测域名。方法使用CLIP式目标函数，将流量编码器与域名文本编码器对齐，其中流量侧仅使用包间隔时间、包大小和方向等side-channel特征，域名侧作为文本监督信号参与表示学习。预训练完成后冻结流量编码器，并通过线性分类器进行下游域名分类，同时引入域名规范化与按时间切分的数据划分策略，以增强任务的现实性与稳定性。

## 3. 结果与结论  
在大规模QUIC流量数据集上进行评估，采用“Week 1训练、Week 2–4测试”的时间划分设置，以模拟真实分布漂移场景。实验结果显示FlowCLIP在后续测试周上整体优于XGBoost与1-NN等强基线方法，在准确率、macro F1与weighted F1等指标上均表现更优，同时也具有可接受的运行开销。结论表明，原始域名可以作为有效的文本监督信号，帮助学习具有跨时间泛化能力的加密流量表示。

## 4. 局限与适用边界  
方法依赖域名作为监督信号，但在DNS隐藏或Encrypted Client Hello广泛部署的环境下，该信号可能不可获取，从而限制适用性。从现有文本无法确认模型在跨协议（如非QUIC流量）或更强对抗条件下的表现稳定性。此外，实验主要基于特定QUIC数据集与时间划分设置，其在更复杂真实网络环境中的泛化能力仍需进一步验证。

## Abstract
Network traffic classification enables website fingerprinting, intrusion detection, and Quality of Service management. However, developing methods that capture stable and generalizable traffic patterns under realistic deployment conditions remains challenging. We introduce FlowCLIP, a contrastive pretraining framework for domain name prediction from encrypted traffic using only side-channel features: packet inter-arrival times, packet sizes, and packet directions. FlowCLIP uses raw domain names as textual supervision by aligning traffic flow representations with domain name representations through a CLIP-style contrastive objective. The pretrained traffic encoder is then frozen and evaluated through linear probing on canonicalized domain name labels. We evaluate FlowCLIP on a large-scale QUIC traffic dataset using a time-based protocol, where models are trained on Week 1 traffic and evaluated on traffic from Weeks 2-4. FlowCLIP outperforms competitive machine learning baselines across later evaluation weeks, suggesting that raw domain names provide a textual supervision signal for learning transferable encrypted traffic representations.

## 4. 方法详解  

### 4.1 问题定义（Section IV-A）  
- 输入：bidirectional flow  
  $$x_i = \{(t_i, size_i, direction_i)\}$$  
- 标签：raw domain name $s_i$  
- 目标：学习 encoder $f(\cdot)$，使  
  $$f(x_i) \rightarrow g(s_i)$$

---

### 4.2 FlowCLIP架构  

#### （1）Traffic Encoder  
输入仅side-channel特征：  
- packet inter-arrival time  
- packet size  
- packet direction  

输出：flow embedding  
$$z_i = f_\theta(x_i)$$  

---

#### （2）Domain Name Encoder  
- 将域名拆分为层级结构（subdomain → TLD）  
- 文本编码器（类似CLIP text encoder）  
$$y_i = g_\phi(s_i)$$  

---

#### （3）CLIP-style对比学习目标（核心）  
批量内 InfoNCE：  
$$
\mathcal{L} = - \sum_i \log \frac{\exp(z_i \cdot y_i / \tau)}{\sum_j \exp(z_i \cdot y_j / \tau)}
$$  

目标：  
- matched (flow, domain) 对拉近  
- mismatched 对拉远  

---

### 4.3 训练与下游任务  
- pretraining：contrastive learning  
- downstream：freeze encoder + linear probe  
- label：canonicalized domain names
