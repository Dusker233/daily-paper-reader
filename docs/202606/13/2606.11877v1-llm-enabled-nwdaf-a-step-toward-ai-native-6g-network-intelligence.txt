# ABSTRACT 

The Network Data Analytics Function (NWDAF) is central to enabling zero-touch network management in fifth-generation (5G) networks by supporting real-time analytics and closed-loop automation. Despite its critical role, open-source NWDAF implementations remain limited in scope and accessibility. In this paper, we develop an open-source NWDAF, compatible with the open-source core network Free5GC, that collects network data via subscriptions to Network Functions (NFs), and also includes an integrated Large Language Model (LLM) interface that enables natural language interaction with human operators. The interface processes user intents, encodes them using a semantic embedding model, and maps them to one of seven predefined intent categories to trigger analytics queries or event subscription commands. This architecture abstracts the complexity of traditional interfaces, allowing non-expert users to manage network analytics and subscriptions with ease. The system supports Access and Management Function (AMF) and Session Management Function (SMF) event subscriptions, real-time monitoring, and analytics retrieval via Prometheus, all accessible through a conversational interface. By bridging AI-driven intent recognition with standardized network analytics, our implementation enhances operator usability and provides a foundation towards AI-native 6G networks. The source code and datasets generated during the current study are available in the github repository, https://github.com/HenokDanielbfg/testbed. 

Keywords: 5G Core Network, 6G, LLM Interface, NWDAF, Open-Source Testbed 

# Introduction 

In the rapidly evolving landscape of telecommunications, the integration of open-source software has revolutionized the development and deployment of 5G testbeds, paving the way for innovative research and practical experimentation in next-generation wireless networks. 5G networks adopt a modular and service-oriented architecture known as Service-Based Architecture (SBA), designed to support diverse requirements across eMBB, mMTC, and URLLC 1, thereby paving the way for intelligent use cases such as smart cities, extended reality (XR) and autonomous systems 2, 3 . One example of a use case is the VICA counseling robot, which leverages 5G/6G features such as network slicing and Multi-access Edge Computing (MEC) to achieve real-time responsiveness for conversational AI services 4. Within SBA, NFs operate as independent microservices that can dynamically discover and communicate with each other through standardized interfaces. Open-source projects such as Free5GC, Open5GS, UERANSIM, srsRAN, and OpenAirInterface (OAI) provide flexible environments for experimentation, enabling developers and researchers to explore, customize, and validate 5G capabilities 5–9 .To enable data-driven intelligence, the Third Generation Partnership Project (3GPP)-Release 15 introduced the NWDAF, which aggregates and analyzes data from multiple NFs 10, 11 . The NWDAF is designed to play a pivotal role in enabling closed-loop automation in 5G by facilitating the exchange of analytics across NFs. This functionality underpins emerging paradigms such as zero-touch network and service management, where the network can respond autonomously to real-time changes 12, 13 . Recent studies have demonstrated NWDAF’s potential to support life-cycle automation and predictive control in slicing and orchestration scenarios 14 .At the same time, there is increasing demand for tools that make these systems more accessible, both for operators and orchestrators, by abstracting away low-level control in favor of higher-level intent. This vision is embodied in the emerging paradigm of Intent-Based Networking (IBN), which seeks to enable operators to express desired outcomes rather than execution steps, enabling high-level declarative control that is translated into deployable configurations through intent translation systems 12, 15 . The authors in 16 have compiled a document that explains the concepts and definitions of IBN. This approach has already been prototyped in private 5G networks using natural language processing to simplify configuration and 1

orchestration 17 .IBN represents a shift from procedural to declarative network management. Instead of adjusting configurations through Command Line Interfaces (CLI) or Application Programming Interface (API) calls, operators can define objectives such as “ensure low latency for this application” or “monitor registration failures in region X,” leaving the system to resolve these intents through underlying analytics and control loops. This paradigm aligns naturally with the SBA of 5G. However, despite this architectural flexibility, open-source 5G networks currently lack native interfaces to support IBN functionality. Moreover, as the industry progresses toward 6G, the ability to manage immersive and massive communication workloads will become central in enabling Metaverse applications. These use cases demand not only high bandwidth and ultra-low latency but also intelligent orchestration frameworks capable of adapting to dynamic user behavior and heterogeneous network environments 18 . Semantic interfaces and AI-driven automation, such as those provided by LLM-augmented NWDAF, offer a critical foundation for simplifying management in these emerging systems 19 . Combining natural language interaction with real-time analytics supports the adaptive infrastructure needed for 6G Metaverse environments. To address the above challenges, we introduce an LLM-powered intent interface built on top of the NWDAF. In most open-source platforms, NWDAF implementations are limited to metrics exposure and lack the user-facing flexibility required to translate human goals into analytics-driven actions. Our NWDAF collects data directly from the core through NF event subscriptions, capturing UE registration/deregistration, session setup, and handover events in real time. These event-driven datasets form the foundation for analytics retrieval and prediction. Additionally, our proposed system integrates an LLM interface into the NWDAF, allowing human-centric network control using natural language. This enables analytical queries such as “show me handover frequency by SUPI” or control intents such as “unsubscribe from AMF events,” which are parsed, interpreted, and executed in real time. The interface acts as a translator between human-readable intents and NWDAF-compatible API calls, making analytics retrieval and event subscription management accessible to users without requiring domain-specific scripting knowledge. Similar efforts have shown that LLMs can accurately translate high-level network queries into actionable tasks in core network environments 20, 21 .At the core of our LLM interface is an intent classification and translation module. Our system follows a Retrieval-Augmented Generation (RAG) paradigm, where user prompts are semantically matched against a repository of predefined intents before being executed as analytics queries or subscription commands. Once classified, the system communicates with the appropriate internal representation (e.g., REST API calls) to fulfill the intent. This modular design allows the interface to remain extensible; new intent classes or analytics types can be incorporated without overhauling the system architecture 22 .This integration of LLMs into NWDAF not only advances research in IBN for 5G, but also opens the door to more human-in-the-loop experimentation frameworks where real-time network analytics can be explored through natural interaction. The system lowers barriers for researchers, students, and network operators who wish to explore 5G behaviors without writing custom code or understanding the intricacies of NF interfaces. As the 5G landscape moves toward 6G and beyond, such interfaces will likely become a necessary part of cognitive, adaptive network infrastructure 23 . Our contributions can be summarized as follows: • We extend Free5GC with a fully functional NWDAF that supports AMF/SMF event subscription and real-time notification handling. • We integrate an LLM-powered intent interface to the NWDAF for real-time interaction, enabling both analytics queries and subscription management. • We generate rich network event datasets from AMF and SMF via NWDAF subscriptions, using a custom mobility model in UERANSIM to simulate dynamic UE behavior and trigger mobility-related events. • We evaluate the LLM interface’s intent classification capabilities, achieving 98.43% accuracy across seven operational categories. • We release our codebase as open-source to support future research on NWDAF capabilities in open 5G testbeds. The remainder of this paper is organized as follows: Section reviews existing open-source 5G projects and related work. Section outlines the system architecture of 5G networks, describing the core, RAN, and UE components. Section presents implementation details, including data collection, event subscription mechanisms, and the LLM interface. Section discusses test results and network performance evaluation. Finally, Section concludes the paper and highlights future directions in 5G network simulation and analytics.

# Related Work 

The transition to SBA in 5G core networks and the virtualization of Radio Access Networks (RAN) have driven extensive research in 5G core development, User Equipment (UE) behaviour, and data analytics. This section explores current works in these areas, focusing on 5G core and RAN implementation, NWDAF integration, IBN in 5G, and mobility modeling. 

5G Core and RAN Implementation 

Several projects have emerged in the area of open source 5G implementations, each contributing uniquely to the development and testing of 5G technologies. Open5GS is an open-source project designed for building and managing new radio/long-term evolution (NR/LTE) mobile networks. It offers a comprehensive 5GC implementation, adhering to 3GPP Release 17 standards. Open5GS provides flexibility and scalability, making it suitable for both research and commercial deployments 8, 24 .UERANSIM stands out as an open-source 5G UE and RAN simulator, offering simulation capabilities for both UE and gNodeB 9. SrsRAN is an open-source project offering a complete suite for 4G and 5G RAN and core networks. It includes implementations for eNodeB (4G), gNodeB (5G), and UE, along with a core network for LTE 6. OpenAirInterface (OAI) provides open-source implementations for both 5GC and RAN. The OAI 5GC project aims to deliver a 3GPP-compliant 5G standalone core network with a rich feature set, while the RAN project focuses on implementing the 5G NR interface 7. IEEE 5G/6G Innovation Testbed is a cloud-based, end-to-end 5G network emulator developed by IEEE to facilitate the testing and experimentation of 5G and emerging 6G technologies 25 . However, although it is composed of open-source components, the project itself is subscription-based. Free5GC is an open-source implementation of the 5GC network based on 3GPP Release 15 and beyond. It supports key functions such as the access and mobility management function (AMF), session management function (SMF), user plane function (UPF), and network repository function (NRF), and adopts a modular SBA 26 . Designed for research and prototyping, Free5GC enables RESTful inter-function communication. 

NWDAF Integration 

A federated learning-based architecture for NWDAF is proposed in 27 to mitigate overloading and data privacy issues. Their design features two components: leaf NWDAFs, deployed within each NF to create local models, and a root NWDAF, deployed in the core, which aggregates the locals into a global model. Notably, their work is conceptual, offering an architectural framework and use-case design. The authors in 28 employ an NWDAF in analyzing a dataset from a simulated 5G network. The analysis particularly focuses on leveraging machine learning models to classify three kinds of network protocols. They tested 2 models (Random Forest and Decision Tree), and achieved an average accuracy of approximately 65%. In 29 , the integration of NWDAF with Open5GS and UERANSIM is detailed. This work describes the collection of control-plane signaling data over a 138-minute period by leveraging the 5G service-based architecture to monitor inter-NF communications, such as BSF-NRF interactions, and using these insights to propose optimal placements for core NFs. The resulting dataset is open-sourced and available on GitHub. In 30 , the authors develop an NWDAF compatible with Free5GC. The NWDAF’s architecture aligns with that of the other Free5GC NFs. Their module comprises a model training logical function (MTLF) for training machine learning models and an analytics logical function (AnLF) for delivering inference results to consumers 31 . They also successfully registered the NWDAF with the NRF. For analytics, they utilize the MNIST dataset, leaving the integration with other NFs for live data collection and analytics as a future step. Their code is available on GitHub, which we have used as a foundation for our current implementation. 

Intent-Based Networking in 5G 

The integration of IBN into 5G infrastructures has emerged as a promising approach to achieve autonomous, intelligent control over network behavior. Recent works have explored various architectural and practical dimensions of this integration, advancing the capabilities of closed-loop automation. A foundational architecture for IBN in 5G is introduced by 32 , who present an Intent Controller capable of translating high-level objectives into enforceable policies. Their system supports self-configuration and optimization via modules for intent translation, policy enforcement, and continuous audit feedback, enabling full closed-loop control. Expanding on usability, 17 

propose a natural language processing (NLP)-powered Intent Engine tailored to simplify private 5G management. Their system allows operators to specify intents in natural language, which are parsed into structured policies for tasks such as slice provisioning, user positioning, and edge service orchestration, demonstrating low-latency translation and ease of use for non-expert stakeholders. To further enhance automation, 33 combine IBN with the 3GPP-defined NWDAF function to realize proactive service assurance. By leveraging AI-driven analytics to forecast traffic and detect anomalies, their hybrid framework enables preemptive slice scaling and resource allocation. This convergence of analytics and intent control illustrates the synergy between IBN and

Mobility Modeling 

Several academic literatures have discussed different simulated mobility models as they pertain to user behavior in a network. Here, we will consider 3 mobility models: The Real-Life Mobility Model (RLMM) 34 captures the cyclic routines of a typical working individual by defining discrete behavioral states, such as at-home , at-work , at-popular-place , and distinct travel modes for regular and alternative routes. Each mobile user is assigned static locations for home and work, alongside a personalized set of social destinations. The model introduces behavioral divergence between weekdays and weekends, with customizable pause times and commute distances, effectively emulating daily life rhythms. Building on structured daily behavior, the Working Day Movement Model (WDMM) 35 integrates multiple submodels to simulate a full working day cycle. Nodes transition through scheduled activities beginning with a randomized wake-up time, followed by morning commutes, extended work periods, and optional evening outings. Intra-office dynamics are captured using Pareto-distributed pause times, while community formation emerges through shared public spaces and coordinated after-hours activities. This composite design yields mobility traces that reflect both individual and social tendencies. In contrast to purely schedule-based models, the Weighted Waypoint Model (WWP) 36 introduces a probabilistic framework grounded in location popularity. Targeted primarily at pedestrian behavior in campus-like environments, it uses a time-aware Markov chain to guide destination selection based on real-time popularity weights. Locations such as classrooms, libraries, and cafeterias are assigned distinct pause-time distributions. Classrooms tend to follow bell curves, while libraries exhibit heavy-tailed patterns, adding temporal depth and heterogeneity to user movement. Together, these models span a wide spectrum of mobility behaviors, from structured routines and socially driven schedules to probabilistic destination preferences, providing a comprehensive foundation for simulating realistic user dynamics in networked systems. 

# 5G System Architecture 

Core Network 

5G systems adopt a SBA, marking a major departure from the tightly-coupled, hierarchical designs of earlier mobile cores 37 .In SBA, each NF exposes its capabilities as discrete services over standardized Service-Based Interfaces (SBIs), typically RESTful APIs 38 . Because communication is stateless and endpoint-agnostic, an NF can discover and invoke any other NF dynamically rather than relying on pre-configured links. Central to this arrangement is the Network Repository Function (NRF), which maintains a registry of all active NFs and their service profiles 39 . When, for example, the AMF must engage the SMF, it queries the NRF, selects an available SMF instance, and establishes a transient connection. This mechanism enables on-the-fly load balancing, rapid horizontal scaling, and automatic failover across redundant NF instances. SBA also applies a producer-consumer paradigm: any NF can simultaneously publish a service (act as producer) and subscribe to external services (act as consumer). That decoupling supports incremental feature growth; new services can be introduced without altering existing components, provided they register with the NRF and conform to the common SBI framework. 

Radio Access Network (RAN) 

In the 5G New Radio (NR) RAN, the base station (gNodeB) integrates both control-plane and user-plane logic in alignment with 3GPP specifications 40 . The control plane (CP) manages tasks such as radio-resource control (RRC), mobility, and QoS negotiation, while the user plane (UP) conveys data employing PDCP, RLC, MAC, and PHY layers. Communication between gNBs and the core utilizes the NG interface, divided into N2 (signaling) which uses the NG Application Protocol (NGAP) for registration, session setup, and mobility control and N3 (user plane) which tunnels user traffic over GTP-U toward the User Plane Function (UPF) 41, 42 . This two-channel split allows independent scaling and optimization of signaling and data transport paths, a foundation for ultra-low-latency and high-throughput use cases.

User Equipment (UE) 

A 5G User Equipment stack comprises of a Non-Access Stratum (NAS) layer that negotiates registration, authentication, and session management with the core 43 and an Access Stratum (AS) layer that implements the radio protocol stack and interacts with the RAN 44 .UE operation is typically represented by a state machine cycling through idle , connected , and inactive modes. These states govern paging, handover behavior, and power-saving features. To maintain service quality, UEs continuously measure metrics such as signal strength and throughput, reporting them to the network for mobility and scheduling decisions 44 .In combination, these three layers, SBA-driven core, NR-based RAN, and standards-compliant UE, form the baseline architecture for 5G deployments. 

# Implementation 

Our implementation comprises three main components: the 5G Core Network, Radio Access Network, and User Equipment simulation, as shown in Fig. 1. Each component is implemented using open-source software and configured to create a comprehensive testing environment. 

Core Network Implementation 

The core network is implemented using Free5GC. This platform supports both experimental research and real-world deployments by offering a comprehensive suite of NFs, each responsible for specific tasks within the 5G core 45 . In this architecture, the control plane operations, service discovery, and user plane traffic are efficiently managed through dedicated NFs 26 . Below is a breakdown of these functions: AMF (Access and Mobility Management Function): The AMF is responsible for managing initial registration, connection setup, and mobility for UEs 46 . It maintains UE context and tracks location updates to ensure seamless handovers as users move across the network 46 . Additionally, the AMF coordinates with other functions such as the SMF and AUSF to establish secure communication sessions 47 .SMF (Session Management Function): The SMF is tasked with establishing, modifying, and terminating data sessions for users 26 . During session setup, it collaborates closely with the AMF to ensure appropriate connection parameters are used. The SMF also configures the UPF to route and manage user data in accordance with session requirements and network slicing strategies 46 .

UPF (User Plane Function): The UPF handles the forwarding of data packets and ensures low-latency routing for user traffic. It enforces Quality of Service (QoS) policies and makes intelligent routing decisions to enhance network performance. Serving as a bridge between the control and user planes, the UPF interfaces with both radio access networks and external data networks 46 .NRF (Network Repository Function): The NRF acts as a centralized service registry, maintaining an updated list of available NFs 45 . By using RESTful APIs, it facilitates efficient service discovery and dynamic communication among NFs 42 . This enables other NFs to locate and interact with appropriate services within the 5G core 31 .AUSF (Authentication Server Function): The AUSF is responsible for authenticating users and devices, ensuring that only authorized subscribers gain access to the network. It works in conjunction with the UDM to verify subscriber credentials and establish secure connections 38 . The AUSF plays a pivotal role in initiating the security handshake processes across the 5G network. CHF (Charging Function): The CHF monitors data usage and session metrics to generate accurate charging and billing information 42 . It integrates with the PCF to apply real-time charging rules and manage user tariffs effectively. This ensures that users are billed appropriately based on their data consumption. N3IWF (Non-3GPP Interworking Function): The N3IWF facilitates connectivity between the 5G core and non-3GPP networks, such as Wi-Fi or fixed broadband. It provides protocol translation and supports seamless handover, maintaining service continuity as users transition between different access networks 26 . Through this capability, the 5G core can extend its reach to a broader range of devices and access technologies. NSSF (Network Slice Selection Function): The NSSF determines the most suitable network slice for each UE, based on service demands and subscription profiles 47 . This ensures that users receive the appropriate QoS and resource allocation as defined by their selected network slice. The NSSF supports multi-tenancy and enhances efficiency by adapting network behavior to fit different use cases. PCF (Policy Control Function): The PCF makes real-time policy decisions that influence session parameters and overall network behavior. It enforces charging regulations, QoS guidelines, and access restrictions, ensuring optimal use of network resources. Working with the SMF, the PCF can dynamically update configurations based on current network conditions 26 .UDM (Unified Data Management): The UDM serves as the central hub for subscriber data, including authentication credentials, user profiles, and service entitlements 45 . It provides vital information to functions such as the AUSF to support secure access. The UDM also ensures consistency of user data across the network, facilitating seamless management 42 .UDR (Unified Data Repository): The UDR is a persistent storage solution for subscriber data and network policies. It collaborates with the UDM to maintain high availability and consistency of critical information. In addition to current data, the UDR stores historical session records and other essential information used for analytics and policy enforcement 26 .Moreover, we have implemented comprehensive event subscription mechanisms within the AMF and SMF. These functions expose RESTful APIs that allow other NFs to subscribe to specific network events. The AMF supports subscriptions for UE registration, deregistration, handover updates, and connectivity state changes. Similarly, the SMF provides subscription capabilities for session management events, including PDU session establishment and modifications. More details on how these subscriptions work can be found in our conference paper 48 .

NWDAF 

The NWDAF architecture is shown in Fig. 2. The process of event subscriptions that the NWDAF utilizes is shown in Fig. 3. This component collects data from other NFs and processes it to generate network insights to interested parties 49 . Our implementation of the NWDAF builds on the work of 30 who laid out the Free5GC based design of the NF. Our contribution to it includes the addition of the “service” module, data collection mechanism, prediction models, and LLM interface for managing subscriptions and analytical insights. The NWDAF integrates with the core by first registering itself with the NRF where it advertises its analytical services 50 . NWDAF reads from an easily configurable YAML file containing a list of events to subscribe to, pertaining to each NF and subscribes to said events via the consumer module. Our implementation currently supports subscriptions to AMF and SMF events. In addition to its event subscription and notification mechanisms, the NWDAF enhances the core network by integrating predictive analytics that forecast critical network events. By continuously analyzing both historical and real-time data collected from NFs, the NWDAF has the ability to predict key parameters such as the most probable handover cell for user equipment, the expected duration of registration states, and future variations in active user counts. This forecasting layer empowers the network to proactively adjust resource allocation and optimize mobility management, thereby reducing latency and enhancing overall service quality. Currently, we have one prediction model in the core, which predicts the next handover cell for a specific UE.

The system follows a Retrieval-Augmented Generation (RAG) paradigm to match user input with pre-defined intent categories and then routes the query accordingly. The system incorporates a flexible mechanism for interpreting operator requests by combining intent embeddings, semantic similarity matching, and function routing. At its foundation, the interface maintains a repository of known intents and their associated categories, stored in a structured text file. These entries represent the different types of requests an operator might issue, ranging from analytical queries such as “How many UEs are active?” to control operations like “Unsubscribe from SMF events.” Each intent is explicitly linked to a category, for instance Analytics Query, AMF Subscribe, or SMF Unsubscribe, which later guides the choice of system function to be invoked. To support robust and naturalistic interactions, the interface uses an embedding model to represent both the stored intents and the incoming queries as high-dimensional vectors. These embeddings are designed to capture subtle aspects of meaning and linguistic variation, enabling the system to handle operator requests even when phrased differently from the stored reference forms. For example, a query such as “Show me the number of currently active users” would be recognized as equivalent to “How many UEs are active?” despite differences in wording. This ability to abstract beyond surface-level text patterns is essential in real-world environments, where operators often rely on shorthand expressions, colloquial phrasing, or paraphrased instructions. When an operator issues a query, the system generates its embedding using the same model applied to the intent repository. It then computes the cosine similarity between the query vector and all stored intent vectors. The entry with the highest similarity score is identified as the most relevant intent, and the corresponding category is retrieved. This classification step is critical, as it determines the downstream system behavior and ensures that even ambiguous or loosely phrased queries can be mapped to a precise and actionable instruction. Once the intent has been classified, the system maps the associated category to a predefined function call. If the identified category corresponds to an analytics operation, the system invokes a Prometheus query function. This function is responsible for constructing a PromQL statement, submitting it to the Prometheus server, and collecting the resulting metric data. The raw response, which may include time series data or counters, is then prepared for higher-level interpretation. On the other hand, if the category corresponds to subscription management, the system instead initiates a control operation by sending a POST request to the NWDAF endpoint. This request contains a JSON payload specifying the desired action, such as subscribing or 

8/20 unsubscribing, along with details of the target network function. In this way, the classification outcome directly determines whether the system operates in an analytical or control capacity. The final stage of the workflow involves generating a user-facing response that translates raw data or confirmation messages into human-readable summaries. To achieve this, the system integrates the large language model into the response pipeline. The retrieved data, whether from Prometheus or the NWDAF REST API, is provided to the model in JSON format. Alongside this structured input, the message context also includes a system prompt that defines the role of the LLM, the original user query, and the function’s result message. By layering these elements together, the model is able to generate explanations that are not only factually accurate but also contextually appropriate. For instance, when metric data is returned, the LLM may produce a summary such as “Currently, there are 52 active UEs registered across all gNodeBs.” In the case of control operations, the model may respond with a confirmation message such as “Successfully unsubscribed from AMF event notifications.” Through this design, the intent classification and processing pipeline ensures that operator requests, regardless of phrasing or complexity, can be accurately understood and translated into meaningful system actions. The use of embeddings for semantic similarity, combined with dynamic routing of function calls and natural language response generation, enables a high level of flexibility. It also supports an interaction style that is closer to natural conversation, reducing the need for operators to learn rigid command syntax and allowing them instead to focus on operational objectives. 

RAN & UE Implementation 

The RAN is implemented using UERANSIM, an open source, software-based 5G RAN simulation tool that provides a comprehensive environment for emulating real-world 5G behaviors and supports research, testing, and validation of various deployment scenarios. It enables the deployment of multiple gNodeB instances, each configured with coverage parameters to mimic varied cellular environments 9. The system supports complete integration with the Next Generation Core (NGC) network by handling control plane signaling via the NG Application Protocol (NGAP) over the N2 interface and managing user plane traffic through the GTP-U protocol over the N3 interface, ensuring that the simulated network adheres closely to real-world 5G architectures 41 . gNodeB instances are further designed to execute advanced radio resource management, dynamically allocating resources based on Quality of Service (QoS) requirements and facilitating seamless inter-gNodeB handovers to maintain continuous connectivity as UEs move across cells 9. In parallel, UERANSIM’s robust UE simulation capabilities enable the emulation of realistic user devices that support multiple PDU session types, including IPv4, IPv6, or dual-stack configurations, with each simulated UE operating with a complete 5G NAS protocol stack to accurately test processes such as network attachment, session establishment, and mobility management. This environment allows for fine-tuning of various network parameters, providing a versatile platform for in-depth analysis and optimization of both control and user plane interactions.

# Data Generation and Analysis 

We evaluated the NWDAF-enhanced 5G network testbed over a two-week period to analyze the behavior of the mobility model and assess the operational capabilities of the NWDAF. The experiment included four virtual gNodeBs, each assigned a distinct tracking area code (TAC) and arranged in a square formation, as illustrated in Fig. 5. Each gNodeB was configured with a simulated coverage radius of 120 units, corresponding to a signal strength threshold of -120 dBm (consistent with UERANSIM’s default configuration). Four virtual UEs were deployed across the network: three configured to dynamically attach and detach from the network, and one configured to maintain continuous connectivity throughout the experiment. Upon joining, each UE began from its designated home location. The simulation environment also included several public locations, such as coffee shops and parks, that UEs could visit, following the defined activity-based mobility model.

Throughout the test period, comprehensive data were collected about UE registration, state transitions, and handovers to evaluate the network’s ability to analyze dynamic user behavior. All registration and deregistration attempts were successful, with the core NFs reliably executing mobility management procedures. UEs exhibited distinct patterns in state durations, with the average time spent in the active state ranging from 100 to 102 minutes, while the inactive state typically lasted between 37 and 40 minutes.

Handover Prediction Model Evaluation 

To evaluate the predictability of the UE handover events as a result of the activity-based mobility model, we employ four classification models on the UE location feature in the collected dataset, namely Random Forest, Gradient Boosting, K-Nearest Neighbors, and Decision Tree, on the dataset. The input features include the UE’s subscriber ID (SUPI), the IDs of the two most recently visited cells, time-of-day (the mobility model’s time categories), the (x, y) coordinates of the most recent (current) cell, and the frequency with which the UE visited that cell at the given time period. We split the dataset into training and testing sets corresponding to 70% and 30%, respectively. Gradient Boosting, with a learning rate of 0.05, maximum depth of 9, and 100 number of estimators, produced the highest accuracy (80.65%), followed by Random Forest (80.24%), while Decision Tree and K-Nearest Neighbors achieved an accuracy 80.11% and 79.03%, respectively. These results suggest that the collected data exhibits predictable patterns, making it a valuable starting point for further NWDAF-driven exploration and analytics. The models we compared are known to be robust against unreliability or low quality of training data 52 .

# Conclusion 

This paper presents the implementation of a software-based 5G network testbed that combines Free5GC, extended with a fully functional NWDAF enhanced by an LLM-powered interface, and UERANSIM, extended with a custom mobility model. We implement event subscription mechanisms for the NWDAF and automate network analysis through a RAG-based LLM-powered NWDAF. Through experimentation, we validated the system’s capability to capture network events, facilitate event-driven analytics, and predict UE behavior based on historical trends. The integration of an LLM-based interface significantly improves the usability of the NWDAF, allowing operators to interact with the system using natural language. A key direction for future development lies in enhancing the LLM interface to support more advanced automation and policy enforcement within the 5G core network. Rather than limiting the LLM to intent classification and basic analytics queries, future iterations can enable the system to autonomously request supplementary data from relevant NFs when needed to fulfill a user’s prompt. This will allow for more dynamic and context-aware responses. Moreover, future work can focus on reducing the cost of leveraging LLMs for these tasks, for example by employing specialized small language models or model compression techniques such as quantization and pruning. Additionally, future work can focus on generating and invoking new

# Appendix 

The following tables present representative samples of the data collected in real-time from AMF and SMF via the NWDAF’s event subscription framework. This data forms the foundation of our analytics and machine learning modules. The NWDAF subscribes to event notifications from both the AMF and the SMF. As subscribed events occur, such as UE registration, PDU session changes, or handovers, the respective NF sends an event report to the NWDAF using HTTP callbacks. These event reports are then parsed, formatted, and exposed as Prometheus metrics by the NWDAF’s internal consumer module. This allows real-time monitoring, querying, and visualization using standard observability tools. In this appendix, we include sample records from three key Prometheus metrics, each of which corresponds to one of the tables below: • Table 2 - Active_UEs : Tracks the number of user devices actively connected to the network at each timestamp, along with the duration they remain in that state. This metric supports session management analysis and capacity planning. • Table 3 - UE_location_report : Captures granular handover data, including the UE identifier (SUPI), the current serving cell (NrCellId), and its location area (TAC). This metric underpins mobility behavior tracking and handover prediction modeling. • Table 4 - UE_registration_state : Logs registration state transitions (active/inactive) per UE, alongside times-tamps and state durations. This data is vital for evaluating user engagement patterns and optimizing registration state transitions. The complete datasets for these metrics are available in the accompanying GitHub repository.
