## 1. 问题与背景  
研究关注在加密网络流量条件下如何进行可靠的流量分类与域名识别，尤其是在QUIC等现代传输协议广泛部署后，传统基于端口号或明文内容的方法逐渐失效。由于TLS加密、DNS over HTTPS以及Encrypted Client Hello等机制，IP地址、域名乃至握手信息的可见性不断降低，使得可用特征变得极其有限。与此同时，现有方法容易依赖数据集偏差或不可复现的标注方式，导致模型在真实环境中泛化能力不足，因此需要一种更稳定且可迁移的表示学习框架。

## 2. 核心思路 / 方法  
论文提出FlowCLIP，一种基于对比学习的预训练框架，将加密流量表示与域名文本表示对齐。方法仅使用包间隔时间、包大小和方向等侧信道特征作为输入，同时引入CLIP式对比目标，让流量编码器与域名文本编码器映射到同一表示空间中进行匹配学习。域名被直接作为监督信号，并通过结构化表示（如按层级拆分）增强语义信息表达。预训练完成后冻结流量编码器，并通过线性分类器在规范化域名标签空间上进行下游预测，从而提升迁移能力与稳定性。

## 3. 结果与结论  
在大规模QUIC数据集上进行实验，采用按时间划分的评估方式，即使用第1周数据训练，在第2至第4周数据上测试，以模拟真实分布漂移场景。实验结果显示，FlowCLIP在多个指标上均优于包括XGBoost和1-NN在内的强基线方法，尤其在后续时间窗口中表现出更稳定的性能优势。整体结论认为，引入原始域名作为文本监督信号能够有效学习可迁移的加密流量表示。

## 4. 局限与适用边界  
方法依赖域名作为监督信号，因此在域名不可见或被完全加密（如ECHO等更强隐私机制广泛部署）时适用性可能下降。同时实验主要基于QUIC流量与特定时间划分设置，其跨协议或跨网络环境的泛化能力从现有文本无法完全确认。此外，域名规范化与标签构建过程可能影响最终性能，对实际部署仍存在一定约束。

## Abstract
Network traffic classification enables website fingerprinting, intrusion detection, and Quality of Service management. However, developing methods that capture stable and generalizable traffic patterns under realistic deployment conditions remains challenging. We introduce FlowCLIP, a contrastive pretraining framework for domain name prediction from encrypted traffic using only side-channel features: packet inter-arrival times, packet sizes, and packet directions. FlowCLIP uses raw domain names as textual supervision by aligning traffic flow representations with domain name representations through a CLIP-style contrastive objective. The pretrained traffic encoder is then frozen and evaluated through linear probing on canonicalized domain name labels. We evaluate FlowCLIP on a large-scale QUIC traffic dataset using a time-based protocol, where models are trained on Week 1 traffic and evaluated on traffic from Weeks 2-4. FlowCLIP outperforms competitive machine learning baselines across later evaluation weeks, suggesting that raw domain names provide a textual supervision signal for learning transferable encrypted traffic representations.

## 4. 方法详解

### 4.1 问题定义
- flow：双向五元组聚合
- 输入：  
  $$x_i = \{(t_i, s_i, d_i)\}$$  
  - $t_i$：时间间隔  
  - $s_i$：包大小  
  - $d_i$：方向  

目标：学习 encoder $f(x)$，使其可用于 domain prediction。

---

### 4.2 FlowCLIP整体架构

**双编码器结构：**
- Traffic Encoder：$f_\theta(x)$
- Domain Text Encoder：$g_\phi(s)$

映射到同一 embedding space：

$$z_i = f_\theta(x_i), \quad y_i = g_\phi(s_i)$$

---

### 4.3 CLIP式对比目标

InfoNCE loss：

$$
\mathcal{L} = -\log \frac{\exp(\text{sim}(z_i, y_i)/\tau)}{\sum_j \exp(\text{sim}(z_i, y_j)/\tau)}
$$

- 正样本：flow ↔ domain name
- 负样本：batch内其他 domain

---

### 4.4 域名建模方式

- 将 domain 按层级拆解：
  - e.g., `music.youtube.com`
- 转换为 token sequence
- 形成 structured textual supervision

---

### 4.5 下游任务

- 冻结 encoder $f_\theta$
- 线性分类器：
$$
\hat{y} = W f_\theta(x)
$$
