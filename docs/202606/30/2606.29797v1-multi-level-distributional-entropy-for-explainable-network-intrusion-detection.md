## 1. 问题与背景  
该论文关注网络入侵检测系统（IDS）在流量级数据上的特征表达不足问题，即现有方法主要依赖聚合流统计（如包数、字节数、时长），但会丢失流量的分布结构信息。与此同时，传统熵方法通常需要原始包序列，而在主流IDS数据集（如NSL-KDD、CICIDS系列）中往往只能获得预聚合特征，从而限制了信息论方法的应用。该问题之所以重要，是因为当前高精度模型在跨数据集和真实环境中的泛化能力较弱，且评估指标可能掩盖真实检测失败。

## 2. 核心思路 / 方法  
论文提出 Multi-Level Distributional Entropy（MDE）框架，直接从流级统计量解析构造熵特征，而不依赖原始包序列或额外训练过程。方法在三个层次上构建特征：流内高斯微分熵（within-flow Gaussian differential entropy）、跨方向 Jensen–Shannon 散度（JSD）、以及 TCP flag 模式的 Shannon 熵，从而刻画不同层级的分布差异。与传统特征工程或深度表示学习方法相比，MDE具有解析定义、无需训练数据、且可解释性更强，并可直接与SHAP结合分析特征贡献。整体上，它将信息论结构显式嵌入流量特征空间，而不是依赖黑盒表示学习。

## 3. 结果与结论  
实验在 NSL-KDD、CICIDS-2017、CICIDS-2018 和 UNSW-NB15 四个数据集上进行，在无数据泄漏的交叉验证与多种评估协议下，仅使用熵特征即可达到 0.708–0.989 的加权F1表现，整体与传统特征方法相当甚至接近。进一步分析发现，虽然整体F1可能较高（如0.74），但检测率（DR）可能仅为0.48，说明聚合指标会掩盖严重误检问题。在时间漂移与伪实时回放实验中，AUC仍可达0.87，但固定阈值下DR下降至0.082，显示模型在真实部署条件下存在显著失效风险。

## 4. 局限与适用边界  
该方法依赖流级聚合统计量推导分布信息，因此无法恢复原始包级序列的细粒度动态结构，在表达能力上存在理论上限。从跨数据集与时间漂移实验来看，模型在固定阈值下性能显著退化，说明其对分布变化较敏感。整体方法更适用于已有流特征数据的分析型IDS场景，而在强动态或高度未知攻击环境中的稳健性仍存在不确定性。

## Abstract
Machine learning network intrusion detection systems (IDS) rely on aggregate flow statistics that discard distributional structure, while established entropy measures require raw packet sequences unavailable in pre-aggregated flow datasets. We propose Multi-Level Distributional Entropy (MDE), an analytical framework that derives interpretable entropy features directly from flow-level summary statistics at three levels: within-flow Gaussian differential entropy, cross-directional Jensen-Shannon divergence (JSD), and Transmission Control Protocol (TCP) flag-pattern Shannon entropy, without raw packet access or training data. Across four benchmarks (NSL-KDD, CICIDS-2017, CICIDS-2018, UNSW-NB15) under a leakage-free fold-local pipeline, entropy-only features achieve weighted F1 of 0.708-0.989, matching conventional features without degrading performance. Full operational metric reporting then exposes failure modes that aggregate F1 conceals. On CICIDS-2018, F1=0.74 hides a detection rate (DR) of 0.48, and on held-out attack families F1 exceeds 0.998 while DR falls to zero. Under temporal shift, a pseudo-live replay of 703K flows reveals a threshold-ranking divergence in which score ranking is preserved (AUC=0.87) but fixed thresholds collapse (DR=0.082) and recalibration offers no recovery. SHapley Additive exPlanations (SHAP) fold-stability analysis (Spearman rho=0.80-0.95) confirms that entropy attributions are reproducible and domain-coherent across heterogeneous environments.

## 4. 方法详解  

### 4.1 MDE整体框架  
输入：流级统计量（mean/std/min/max/packet count/flag counts）  
输出：三层熵特征（7–12维）  

架构（见 Figure 2）：  
1. Flow statistics input  
2. 三层熵构造  
3. 特征拼接（conv + entropy or entropy-only）  
4. 分类器（LightGBM / RF / others）+ SHAP解释  

---

### 4.2 L1：流内高斯微分熵（ADE）  
假设流内 packet size / IAT 服从近似高斯：  
- 基于均值 μ 与方差 σ²解析计算  
- 用于刻画单流内部不确定性  

形式（概念）：  
$$ H(X) = \frac{1}{2}\log(2\pi e \sigma^2) $$  

---

### 4.3 L2：跨方向 Jensen-Shannon Divergence  
- 比较 inbound vs outbound 分布差异  
- 衡量通信对称性/攻击行为偏移  

核心：  
- JS divergence（对称 KL 改进）  
- 捕获扫描 / DDoS 双向不平衡结构  

---

### 4.4 L3：TCP Flag Shannon Entropy  
- 对 FIN/SYN/ACK 等 flag 分布计算熵  
- 反映协议行为复杂度  

---

### 4.5 分类与解释  
- 分类器：LightGBM / RF / TabNet / MLP  
- 解释：TreeSHAP  
- 输出：feature attribution + fold稳定性分析
