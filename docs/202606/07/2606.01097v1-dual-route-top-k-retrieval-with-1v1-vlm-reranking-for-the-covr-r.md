## 1. 问题与背景

论文关注 CoVR-R（Reason-aware Composed Video Retrieval）任务，即根据参考视频和文本编辑指令检索目标视频。与传统视频检索不同，CoVR-R要求模型理解编辑后的状态变化、时间阶段转换、场景约束以及应被移除的视觉内容，因此仅依赖文本匹配或视频相似度容易失效。作者观察到，文本推理检索往往能产生较强的Top-1结果但召回不足，而视觉检索能够补充遗漏候选却容易错误替换最佳结果，因此需要同时解决候选召回和最终选择两个问题。

## 2. 核心思路 / 方法

论文提出一种分阶段的“双路检索+1v1重排序”框架。首先构建基于推理与文本的检索路线，通过VLM生成目标状态描述，并在已有候选集合内部利用VLM slot selector对Top-1进行纠错，但不引入新的视觉候选。随后构建视觉检索路线，将视频转化为contact sheet，利用DFN-H和DFN-L编码器进行视觉检索，以补充文本路线遗漏的候选视频。两条路线合并形成Top-10候选集后，系统采用VLM进行一对一（1v1）比较，让每个挑战者与当前Top-1逐一对决，并通过高置信度、致命错误检查以及多模块共识机制决定是否允许替换当前结果。相比直接进行多候选分类或广泛文本重排序，该方法将“候选召回”和“Top-1决策”明确解耦，并将最终替换控制在保守、低风险的范围内。

## 3. 结果与结论

在隐藏测试集上，最终系统达到95.28%的R@1、97.98%的R@5、98.48%的R@10以及99.66%的R@50。实验显示，不同阶段解决的是不同瓶颈：候选集内部的Top-1选择主要提升R@1，而视觉候选注入主要提升R@5、R@10和R@50等高阶召回指标。作者发现，视觉检索能够有效找回遗漏目标，但不能直接决定最终答案；最稳定的策略是先扩大召回，再通过保守的1v1比较完成最终选择。因此，CoVR-R性能提升的关键在于将候选召回与Top-1替换分离优化，而非依赖统一的大规模重排序过程。

## 4. 局限与适用边界

该系统大量依赖Gemini等VLM进行推理、比较和审核，推理成本与API开销较高，作者甚至未在验证集完整运行最终重排序阶段。从现有文本看，方法完全基于零样本流程验证，其在其他数据集、不同VLM或更大规模视频库上的泛化能力无法确认。此外，该框架主要适用于具有复杂编辑语义和因果推理需求的组合视频检索场景。

## Abstract
We describe \emph{Dual-Route Top-K Retrieval with 1v1 VLM Reranking} for the CoVR-R challenge. The method treats composed video retrieval as two coupled problems: finding a sufficiently complete top-k candidate set, and then safely deciding whether any candidate should replace a strong current top-1. We first improve the reasoning/text seed with a VLM slot selector over existing candidates, without introducing DFN visual retrieval. We then add a visual route from contact-sheet embeddings using DFN-H/DFN-L. The routes are merged into a top-10 candidate set, after which a VLM final reranker performs conservative 1v1 comparisons between the current top-1 and each challenger. On the hidden test split, the final system reaches 95.28 R@1, 97.47 R@5, 98.48 R@10, and 99.66 R@50. The main lesson is that CoVR-R benefits more from recall-selection decoupling than from broad text reranking or direct multi-candidate VLM classification.
